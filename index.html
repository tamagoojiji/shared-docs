よしこさんの認識実際に起きていること

「犬を直してほしい」「私はちゃんとやっている」やっていることは意味がない・間違っている・逆効果である。良かれと思ってやっている行動の多くが、問題行動を強化・悪化させている

競合との重なり

競合被っている領域ゆうりさんとの違い
東京DOGS（13.8万）恐怖・警告型フック豆知識の羅列。個別の犬を「診て」はいない
犬の心理学（3.5万）行動を読み解く心理・行動だけ。身体的原因は扱えない
獣医師にゃんとす（11.4万）専門用語の平易化医療側の視点。行動改善の実践指導はしない
しつけの教科書（5.8万）常識の否定・逆張り目は引くが行動分析の根拠が薄い
三井氏（5.2万）Before/After実演「なぜその行動が出るか」の分析が薄い

ゆうりさんだけの領域

「行動」と「体」の境界線を診れる唯一のポジション。
元看護師のアセスメント力（情報収集→仮説→検証）で、
「しつけの問題か、体の問題か、飼い主の行動の問題か」を切り分けられる。

競合が言えない一言：「それ、しつけの問題じゃないかも。」

看護師スキルの武器化

看護師のスキル犬への応用
バイタルの変化を見逃さない目呼吸・姿勢・表情の微細な変化を読む
トリアージ（優先順位判断）行動の問題か、体の問題かを切り分ける

ゴール：「犬を変える」のではなく、飼い主に行動の仕組みを理解させて、飼い主を変える。
核心：「感情で解釈するな、行動を見ろ」

オペラント条件付け ─ 飼い主が無意識に作った行動

飼い主の反応が犬の行動を強化している。

飼い主の行動犬が学習すること結果
吠えたら振り向く「吠えれば注目される」もっと吠える
引っ張ったら付いていく「引っ張れば前に進める」もっと引っ張る
飛びついたら撫でる「飛びつけば触ってもらえる」もっと飛びつく
おやつで釣って黙らせる「吠えればおやつが出る」吠えが加速

レスポンデント条件付け ─ 犬の脳が勝手に覚えた反応

犬の意思とは無関係に、脳が自動的に結びつけた反応。

きっかけ結びついた記憶自動反応

共感設計 ─ よしこさんの孤独に触れる

よしこさんが人に言えないこと

人に言えない本音なぜ言えないか
「正直、飼わなきゃよかったと思う瞬間がある」犬好きとして許されない気がする
「この子が可愛いと思えない日がある」飼い主失格だと思われる
「散歩が怖い。また吠えたらどうしよう」大げさだと思われる
「夫は何もしないのに犬に好かれてる。ずるい」器が小さいと思われる
「しつけ教室で先生の前ではいい子だった」「大丈夫ですね」で終わって孤立した
「本当は泣いたことがある」こんなことで泣くなんて恥ずかしい

よしこさんの孤立構造

犬がうまくいかない
→
周りに相談
→
「あなたが悪い」と言われる
→
相談しなくなる
→
SNSで同じ悩みを探すここでゆうりさんに出会う

ゆうりさんが最初に触れるべきは「犬の話」ではない

他の発信者

  • 「飼い主がリーダーになりましょう」
  • 「愛情を持って接しましょう」
  • 「こうすれば直ります」（犬の話）
  • 「しつけの基本は〜」

ゆうりさん

  • 「リーダーにならなくていい」
  • 「愛情はある。やり方を知らなかっただけ」
  • 「あなたが辛かったですよね」（飼い主の話）
  • 「泣いたことありませんか？」
最初に犬の話をしない。最初によしこさんの気持ちを言語化する。
それが「この人は私のことわかってる」の正体。

よしこさんが保存する理由は2つだけ：「後で見返したい」 と 「怖くて忘れちゃいけない」

#カテゴリ保存心理推奨頻度
①チェックリスト系「うちの子に当てはまるか確認したい」週1
②「実はそれ逆効果」系「やめなきゃ。忘れそうだから保存」週1
③言い換え・翻訳表系「犬の言葉の正解を手元に置きたい」月2〜3
④手順・ステップ系「やり方を覚えられないから保存」週1
⑤「知らなかった」衝撃系「怖すぎて消せない」月2

保存の構造：感情で止めて、情報で保存させる。この順番が逆だと保存されない。

Section 06

投稿例文 14本（フック→共感→説明→CTA）

構成ルール：フック（3秒）→ 共感（5〜7秒）→ 説明（10〜12秒）→ CTA（3秒）
共感パートで「この人わかってる」を作ってから、説明に入る。情報量より信頼。

① チェックリスト系

チェックリスト リール 30秒
呼んでも来ない。目も合わせない。
0-3sフック：呼んでも来ない犬。飼い主が名前を呼ぶ映像
3-8s共感：「嫌われてるのかなって思いますよね。毎日一緒にいるのに、なんで私だけ。わかります」
8-12s共感（救い）：「嫌ってないです。犬は"嫌う"という感情で動いていません」
12-22s説明：ストレスサインを順に提示（あくび・体を掻く・目をそらす・耳を倒す・尻尾を下げる・固まる・パンティング）「これは"助けて"のサインです」
22-27s「3つ以上当てはまったら、犬は今しんどい状態」
27-30sCTA：「忘れる前に保存」
保存 → 散歩中・日常で「これストレスサイン？」と確認する辞書
保存理由：「嫌われてるかも」と不安になった時に見返して、感情ではなくサインで判断できる
チェックリスト カルーセル 6枚
触ろうとしたら、避けられた。
1枚目フック＋共感：「触ろうとしたら、避けられた。地味にキツいですよね。"私のこと嫌いなの？"って」
2枚目共感（救い）：「嫌いじゃないです。犬には"避ける理由"が必ずあります」
3枚目説明：避ける理由チェックリスト（触り方が苦手 / 過去に痛い経験 / タイミングが悪い / 体のどこかが痛い）
4枚目「"性格"で片付けないで。理由を1つずつ確認してみてください」
5枚目フローチャート図解（状況→原因の切り分け→対応）
6枚目CTA：「心当たりがあったら保存。プロフへ」
保存 → 避けられるたびに見返して原因を特定したい
保存理由：「嫌われてる」で思考停止せず、原因を探すための手引きとして

② 「実はそれ逆効果」系

逆効果 リール 30秒
「静かに！」って叫んでも、もっと吠える。
0-3sフック：飼い主が「静かに！」と叫ぶ → 犬がさらに吠える映像
3-8s共感：「毎日これ。近所に聞こえてると思うと申し訳なくて。もう何回叫んだかわからない」
8-11s共感（救い）：「あなたが悪いんじゃない。叫びたくなるのは当然です」
11-20s説明：「ただ、犬の脳には"声を出してくれた＝反応もらえた"と記録されてます。あなたの"静かに"は、犬にとっては"もっとやって"のサイン」
20-27s「やることは1つ。何もしない。視線を外して、離れる」
27-30sCTA：「忘れる前に保存」
保存 → 叫びそうになった時のブレーキとして
保存理由：「叫ぶのは自然な反応」と許してもらえた安心感＋具体的な代替行動を手元に
逆効果 リール 30秒
おやつ見せた瞬間だけ静かになる。それだけ。
0-3sフック：おやつを差し出して犬を黙らせる飼い主の映像
3-8s共感：「とりあえず静かになってほしい。その気持ち、痛いほどわかります。必死ですよね」
8-11s共感（救い）：「やり方を知らなかっただけ。あなたの愛情は間違ってない」
11-20s説明：「ただ犬の脳には"吠える→おやつが出る"と記録されてます。吠えれば吠えるほどおやつが出る。犬は正しく学習しているだけ」
20-27s「おやつは"静かな時"に出す。タイミングを変えるだけで全部変わります」
27-30sCTA：「保存して今日から実践」
保存 → おやつの出し方を根本から変える
保存理由：「必死だったこと」を否定されなかった安心感。具体策を見返したい

③ 言い換え・翻訳表系

翻訳表 カルーセル 7枚

1枚目フック＋共感：「私がダメって言ったおやつ、夫がもうあげてる。"何回言えばわかるの"って叫びたくなりますよね」
2枚目共感（救い）：「あなたは間違ってない。でも家族がバラバラだと、犬はもっと混乱します」
3枚目説明：家族で統一すべき3つ（声かけ・おやつ・対応ルール）。バラバラだと犬は"人を使い分ける"を覚える
4枚目「お母さんの前では吠えるけど、お父さんの前では静か。それは"舐めてる"んじゃなくて"学習結果"」
5枚目CTA：「家族に黙ってこの投稿送ってください。保存」
保存 → 家族に見せる＋ルール統一の教材として
保存理由：「あなたは間違ってない」に救われた。家族会議の武器として

⑦ 「私だけじゃなかった」共感系

共感 リール 30秒
散歩の時間が近づくと、胃が重い。
0-3sフック：リードを見つめてため息をつく映像
3-8s共感：「また吠えたらどうしよう。すれ違う人に頭下げるのが辛い。帰ってきたらどっと疲れてる」
8-12s共感：「散歩が憂鬱になってるのは、あなたが逃げてないからです。向き合ってるから辛い」
12-15s共感（救い）：「大丈夫です。散歩が"一番楽しい時間"に変わる日は来ます」
15-25s説明：「引っ張る・吠える。全部"やり方"で変えられます。犬を変えるんじゃなくて、歩き方のルールを変えるだけ」
25-30sCTA：「一人で抱えないでください。プロフへ」
保存 → 辛い日のお守り
保存理由：「向き合ってるから辛い」に泣きそうになった。お守りとして消せない
共感 リール 30秒
「飼わなきゃよかった」って思って、そんな自分が一番嫌だった。
0-3sフック：犬と距離を置いてソファに座る飼い主の映像
3-8s共感：「頑張ってるのに報われない。誰にも言えない。"飼い主失格だ"って自分を責めてる」
8-12s共感：「そう思ったことがある人、たくさんいます。あなただけじゃない」
12-15s共感（救い）：「"飼わなきゃよかった"と思うほど追い詰められてたこと。それ自体が、限界まで頑張った証拠です」
15-25s説明：「"可愛いと思えない"のは愛情がないんじゃない。疲れてるだけ。犬はあなたを責めていません。まず自分を許すことから」
25-30sCTA：「明日からできること、一緒に見つけましょう。プロフへ」
保存 → 泣きそうな夜に見返す
保存理由：「限界まで頑張った証拠」に許してもらえた。お守り。絶対に消せない

Section 07

伝え方の鉄則 ─ 翻訳テーブル

よしこさんに専門用語は通じない。すべて「日常の言葉」に翻訳する。

専門用語よしこさんに通じる言い方
オペラント条件付け「あなたの反応が犬の"クセ"を作っている」
レスポンデント条件付け「犬の脳が勝手に覚えた"自動反応"」
正の強化「ご褒美になっちゃってる」
負の強化「嫌なことが消えるから繰り返す」
消去「反応しないと、やらなくなる」
拮抗条件付け「嫌な記憶を、いい記憶で上書きする」
カーミングシグナル「犬の"もうやめて"のサイン」
般化「別の場所でもできるようにする」

絶対に守るトーンルール

絶対に言わない

  • 「飼い主が原因です」
  • 「あなたが間違っています」
  • 「愛情が足りない」
  • 「犬が可哀想」
  • 「なぜもっと早く気づかなかったんですか」

必ずこう言い換える

  • 「やり方が違っただけ」
  • 「知らなかっただけ。大丈夫」
  • 「愛情はある。伝え方を変えるだけ」
  • 「犬は正しく反応しているだけ」
  • 「今日気づけたなら、もう変われます」
鉄則：「あなた」を責めず、「やり方」を差し替える。
犬を変えるのではなく、見方を変えれば犬が変わる、と伝える。
